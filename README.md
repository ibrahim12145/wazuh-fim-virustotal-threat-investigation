# SOC Project: Wazuh FIM + VirusTotal Threat Investigation

A hands-on Security Operations Center (SOC) lab demonstrating **File Integrity Monitoring (FIM)**, security alert investigation, threat hunting, file hash analysis, API integration, and threat intelligence using **Wazuh** and **VirusTotal**.

## Project Overview

This project demonstrates a practical SOC investigation workflow in which a Windows 10 endpoint is monitored by Wazuh FIM. File activity is detected, security events are generated, file hashes are examined, and the resulting hash information is used with VirusTotal for additional threat-intelligence analysis.

### Investigation Workflow

```text
File Added / Changed
        ↓
Wazuh File Integrity Monitoring (FIM)
        ↓
Security Alert
        ↓
Threat Hunting / Alert Investigation
        ↓
File Hash Extraction
        ↓
Wazuh Manager
        ↓
VirusTotal API
        ↓
Threat Intelligence Result
```

## Project Objectives

- Configure a Windows 10 endpoint with a Wazuh Agent.
- Create a dedicated Wazuh monitoring group.
- Configure File Integrity Monitoring for a Windows directory.
- Detect file creation, modification, deletion, and integrity changes.
- Examine file hashes generated by FIM events.
- Investigate security events through the Wazuh Dashboard.
- Integrate Wazuh with the VirusTotal API.
- Use file-hash reputation information as additional threat-intelligence evidence.
- Understand a practical SOC workflow from endpoint activity to threat investigation.

## Wazuh File Integrity Monitoring

The monitored Windows directory was configured for real-time FIM monitoring:

```xml
<agent_config os="Windows">
    <syscheck>
        <disabled>no</disabled>
        <directories check_all="yes" realtime="yes" report_changes="yes">C:\Wazuh-FIM-Lab\directories</directories>
    </syscheck>
</agent_config>
```

The configuration allowed Wazuh to detect:

- File creation
- File modification
- File deletion
- File renaming / integrity changes
- File hash changes
- Before-and-after file information where available

## FIM Testing

The lab first used harmless test activity to validate FIM.

Example PowerShell commands:

```powershell
Set-Content -Path "C:\Wazuh-FIM-Lab\directories\test.txt" -value "Iam Ibrahim"
Add-Content -Path "C:\Wazuh-FIM-Lab\directories\test.txt" -value "iam twenty-one years old"
```

The resulting Wazuh events demonstrated that changes to monitored files could be detected and investigated through the Wazuh Dashboard.

The investigation also examined file hashes and `syscheck.diff` information associated with file changes.

## Malware Investigation

For the malware investigation portion of the lab, the sample referenced in the project documentation was:

```text
Win32.KeyPass.zip
```

Wazuh FIM detected the newly added archive in the monitored directory and generated a corresponding security event.

The investigation focused on the event information and file hash rather than executing the sample.

> **Safety:** Do not execute or extract a malware sample on a normal workstation. The lab focuses on detection, alert investigation, hashing, and threat-intelligence lookup.

## Threat Hunting & Alert Investigation

The Wazuh Dashboard was used to investigate the generated FIM event:

1. Locate the generated FIM event.
2. Review the affected file.
3. Examine file metadata.
4. Review the file hash.
5. Examine available `syscheck` information.
6. Use the hash as an investigation artifact.
7. Perform additional threat-intelligence analysis with VirusTotal.

This demonstrates how a SOC analyst can move from an endpoint event toward evidence-based investigation.

## VirusTotal Integration

Wazuh was integrated with VirusTotal using its API.

Example configuration:

```xml
<integration>
    <name>virustotal</name>
    <api_key>YOUR_VIRUSTOTAL_API_KEY</api_key>
    <group>syscheck</group>
    <alert_format>json</alert_format>
</integration>
```

The configuration belongs in:

```text
/var/ossec/etc/ossec.conf
```

Relevant Wazuh logs include:

```text
/var/ossec/logs/integrations.log
/var/ossec/logs/alerts/alerts.log
```

### API Key Security

Never publish a real VirusTotal API key to GitHub.

The example intentionally uses:

```text
YOUR_VIRUSTOTAL_API_KEY
```

## VirusTotal Investigation Result

The documented investigation showed that **7 security engines detected the analyzed malware sample**.

The VirusTotal result provided additional threat-intelligence evidence associated with the file hash.

A key investigation detail is that a hash for an archive such as `Win32.KeyPass.zip` represents the archive itself. It should not automatically be treated as the hash of files that might exist inside the archive.
